# UI Framework Standard

- Gunakan **shadcn/ui** (React + Tailwind CSS + Lucide Icons) sebagai standar komponen dan antarmuka untuk semua pengembangan frontend web.
- Hindari membuat antarmuka frontend vanilla kuno jika membuat atau meredesain aplikasi web; prioritaskan struktur modern berbasis React + Vite / Next.js dengan komponen standar shadcn/ui.
